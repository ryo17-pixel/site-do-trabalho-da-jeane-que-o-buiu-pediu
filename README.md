# Site de apresentação

Landing page responsiva em HTML, CSS e JavaScript puro para apresentar um
estúdio criativo. Abra `index.html` no navegador ou publique os arquivos
`index.html`, `style.css` e `script.js` em qualquer hospedagem estática.

## Personalização

- Edite os textos, os projetos e o nome "Estúdio Aurora" em `index.html`.
- Troque o endereço de e-mail demonstrativo no link de contato.
- Altere cores, fontes e estilos em `style.css`.
- A foto principal usa uma imagem do Unsplash; substitua a URL em `style.css`
  caso prefira usar uma imagem própria.
